
# Bradesco-Guardian - Contextualização

# 1. Contextualização do Problema

O Pix se tornou o principal meio de pagamento no Brasil pela sua rapidez e praticidade, mas essa mesma facilidade também aumentou os golpes, transferências indevidas e fraudes.

Cada vez mais os usuários dessatentos ficam mais vulneráveis: clicam em links falsos, caem em golpes de “Pix premiado”, fazem transferências por pressão de terceiros ou gastam sem entender o impacto.

Hoje, os responsáveis só descobrem o problema *depois* que o dinheiro já saiu da conta, sem nenhuma forma de pausar, revisar ou bloquear a transação a tempo.

# 2. Público-Alvo

* O Guardian foi pensado para usuários que buscam mais proteção em suas transações via Pix, especialmente aqueles com perfis mais suscetíveis a golpes, como pessoas com pouca familiaridade digital e usuários que precisam de uma camada extra de segurança para suas movimentações financeiras.

# 3. Objetivo da Solução

O objetivo do Guardian é criar uma camada de proteção inteligente entre o usuário e o Pix.Através de uma interface simples e acessível, a solução permite:

* Bloquear automaticamente Pix suspeitos;
* Pausar uma transação para análise antes da confirmação;
* Explicar de forma clara *o porquê* da pausa, sem termos técnicos;
* Dar ao responsável a opção de liberar, bloquear ou falar com um atendente.

Dessa forma, o Guardian não só evita prejuízos financeiros, como também educa o usuário e devolve o controle para quem realmente deve decidir.
